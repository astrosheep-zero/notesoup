# Claude mod type contract

`claude-code.d.ts` is the unmodified declaration file generated by Claude Code
2.1.295 when loading this mod interactively with `claude --plugin-dir mods/notesoup`
on 2026-10-12 (`.claude-plugin/types/claude-code/index.d.ts`).
It is vendored so the mod typecheck works offline, without Claude installed.
`sandbox.d.ts` adds the loader's `import.meta.dir`; Node and DOM types are not included.

After a Claude update, refresh this copy from the generated declaration file.
Keep the generated version header intact. The engine scanner remains authoritative:
`npm test` also runs `claude plugin validate mods/notesoup --strict` when Claude is
installed, and always typechecks the mod against this contract.
